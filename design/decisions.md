# Design Decisions Log

This log records each decision with its rationale, so the design can be reviewed or revised later. New entries go at the bottom. A superseded entry is marked rather than deleted.

| # | Decision | Rationale | Date |
|---|---|---|---|
| D1 | The course targets **IELTS Academic** only. | Focus. The target learners are university and professional applicants. | 2026-11-05 |
| D2 | Entry level is around **6.5**. The exit target is **7.0**. | Band 7 is a common admission and registration requirement. A narrow gap lets the course define its content as the band 6 → 7 boundary in the descriptors. | 2026-11-05 |
| D3 | The design method is **UbD** (backward design), checked with **constructive alignment**. | Professional or accreditation-style rigour. Outcomes come first, and content serves them. | 2026-11-05 |
| D4 | The course has **dual aims**: language competence and test literacy, kept aligned. | It avoids both a tips-only course and a generic EAP course. | 2026-11-05 |
| D5 | Delivery is **one outcome framework at two depths**: a core pathway ("crash course") and an extension bank ("all you can eat"). Lessons, workshops and feedback are **outside** the self-study course. | It serves learners with very different amounts of time. Tagging every item to an outcome keeps the extension bank aligned. | 2026-11-05 |
| D6 | The structure is **four skill modules (L / R / W / S)** with integrating threads (language, test literacy, autonomy) and shared topics. | Skill modules match the test and learner expectations. The threads and topics provide integration without giving up the skill divisions. | 2026-11-05 |
| D7 | **CEFR B2 Vantage** is the base language reference. Higher-level competences are added as the band 7 descriptors require. | C1 includes B2. Vantage is a detailed and usable specification, and no equivalent specification exists at C1. | 2026-11-05 |
| D8 | Practice for each question type is **weighted by its prevalence** in Cambridge IELTS 14–19/20. | Practice time is proportional to the likelihood of meeting the type in the test. | 2026-11-05 |
| D9 | The repo holds the **pre-2023 band descriptors**, chosen because they were available as text. The current (2023) public version is to be added alongside them. | The criteria are unchanged. The current wording is authoritative for alignment, and the older concise wording is a useful basis for learner rubrics. | 2026-11-05 |
| D10 | Files in `ref/` are **reference only**. Course materials are original. | Copyright, and a clear separation between sources and the course. | 2026-11-05 |

## Open questions

- **Q1:** How many notional hours should the core pathway have? (Working estimate: 30–40.)
- **Q2:** Listening and Speaking question and task type taxonomies, ideally with prevalence data.
- **Q3:** The topic list for shared themes.
- **Q4:** Vocabulary policy: which lists define the targets (for example NGWL + NAWL for coverage, EVP for levelling).
- **Q5:** Delivery platform: documents, web, LMS or app. This affects how the extension bank is built and tagged.
- **Q6:** Diagnostic design: a full mock, or a shorter skill-by-skill placement.
